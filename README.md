# دليل السفر البري إلى مكة المكرمة 🕋 (Road to Makkah)

دليل رقمي تفاعلي (PWA) للمسافرين براً إلى مكة المكرمة من دول الخليج والدول العربية المجاورة، يعمل حتى عند انقطاع الإنترنت على الطريق.

الموقع: <https://moathworks.github.io/road-to-makkah/>

## البنية

المشروع موقع ثابت يُبنى بسكربت `build.js` بـ Node.js القياسي دون أي مكتبات خارجية (لا `node_modules`).

| المسار | المحتوى |
| --- | --- |
| `data/shared.js` | رابط الموقع، المقاطع المشتركة للمحطات، قائمة الفحص، التطبيقات المشتركة |
| `data/countries/*.js` | ملف واحد لكل دولة فعّالة (يُكتشف تلقائياً) |
| `data/site.js` | ترتيب الدول في الصفحة الرئيسية وبيانات صفحات «قريباً» |
| `templates/` | قوالب الصفحات (`country.js`, `home.js`, `coming-soon.js`, `sw.js`) |
| `css/style.css` | أنماط صفحات الدول وصفحات «قريباً» |
| `css/home.css` | أنماط الصفحة الرئيسية |
| `js/app.js` | السلوك التفاعلي لكل الصفحات |

الملفات المولّدة (لا تُعدَّل يدوياً): `index.html`، `<دولة>/index.html`، `sw.js`، `sitemap.xml`.

## التعديل والبناء

عدّل ملفات `data/` أو `templates/` أو `css/` أو `js/` ثم شغّل:

```bash
node build.js
```

يحسب البناء تلقائياً: ترقيم المحطات، المسافة المتبقية لكل محطة ونقاط GPS، الوقود والزمن الصافي، بصمات الملفات (`?v=hash`)، قائمة كاش `sw.js`، وتاريخ «آخر تحديث» (تاريخ آخر إيداع غيّر المحتوى، أو اليوم إن وُجدت تعديلات غير مودعة).

## المسافات: مصدر واحد

المصدر الوحيد للمسافات هو الحقل `distanceFromPrevKm` في كل محطة. سلسلة المسار لأي دولة هي:

```text
origin ← outboundStations (ملف الدولة) ← routeSegments.riyadhToMakkah ← destination (shared.js)
```

يفشل البناء برسالة واضحة إذا:

- لم يطابق مجموع المقاطع `totalDistanceKm` للدولة.
- خالف الرقم المكتوب في شارة المحطة («تبعد ~N كم») قيمة `distanceFromPrevKm`.
- تجاوزت المسافة المستقيمة بين نقطتين متتاليتين مسافة الطريق بينهما (إحداثيات أو مسافة خاطئة).
- نقص محطة اسمٌ أو وصف أو رابط خريطة، أو كانت إحداثياتها خارج النطاق الجغرافي المتوقع.

الإحداثيات (`lat`/`lon`) مطلوبة فقط لمحطات سلسلة المسار، وتؤخذ من رابط الخريطة نفسه. المحطة التي لم يُتحقق من موقعها تُترك بلا إحداثيات ويكون رابطها رابط بحث.

## إضافة دولة جديدة

1. أنشئ `data/countries/<code>.js` على نمط `qa.js` (البيانات، `origin`، `routes`، `outboundStations`، `returnStations`).
2. تأكد أن الـ `slug` موجود في `countriesOrder` داخل `data/site.js` (الدول العشر مدرجة مسبقاً).
3. أضف ملف العلم إلى `assets/images/` إن لم يكن موجوداً.
4. شغّل `node build.js`.

تتحول الدولة تلقائياً من صفحة «قريباً» إلى دليل كامل، وتُضاف إلى الصفحة الرئيسية وخريطة الموقع وكاش العمل دون اتصال.
