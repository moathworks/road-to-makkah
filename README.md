# دليل السفر البري إلى مكة المكرمة 🕋 (Road to Makkah)

دليل رقمي تفاعلي (Mobile-First PWA) للمسافرين براً إلى مكة المكرمة من دول الخليج والدول العربية المجاورة، يعمل بالكامل حتى при انقطاع الإنترنت على الطريق.

## البنية المعمارية (Zero-Dependency Static Builder)

يعتمد المشروع على مصدر واحد للبيانات (`data/`) وقوالب موحدة (`templates/`) تُبنى عبر سكربت `build.js` القياسي بـ Node.js دون أي مكتبات خارجية (`node_modules`):

- `data/shared.js`: المقاطع المشتركة للمحطات (الرياض، طريق الرياض–الطائف–مكة، طريق العودة من المدينة)، قائمة الفحص الذكية (بمعرّفات ثابتة)، والتطبيقات المشتركة.
- `data/countries/qa.js`: بيانات ومسارات ومحطات دولة قطر.
- `data/countries/bh.js`: بيانات ومسارات ومحطات مملكة البحرين.
- `data/countries/upcoming.js`: بيانات الدول الثماني قيد الإعداد وترتيب الصفحة الرئيسية.
- `templates/`: قوالب توليد الصفحات (`country.js`, `home.js`, `coming-soon.js`, `sw.js`).
- `build.js`: يتحقق من سلامة البيانات والإحداثيات والمسافات (Validation)، يحسب بصمات الملفات (`?v=hash`)، ويولّد ملفات HTML الثابتة الكاملة، وملف `sw.js`، و`sitemap.xml`، و`robots.txt`.

## طريقة التعديل والبناء

لتعديل أي محطة أو مسافة أو إضافة دولة جديدة، عدّل ملفات `data/` أو `templates/` ثم شغّل:

```bash
node build.js
```

> **تنبيه:** لا تعدّل ملفات `index.html` أو `sw.js` يدوياً لأن `build.js` يعيد توليدها تلقائياً.
