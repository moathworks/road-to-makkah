# دليل السفر البري إلى مكة المكرمة 🕋 (Road to Makkah)

دليل رقمي تفاعلي (PWA) للمسافرين براً إلى مكة المكرمة من دول الخليج والدول العربية المجاورة، يعمل حتى عند انقطاع الإنترنت على الطريق.

الموقع: <https://moathworks.github.io/road-to-makkah/>

## البنية

المشروع موقع ثابت يُبنى بسكربت `build.js` بـ Node.js القياسي دون أي مكتبات خارجية (لا `node_modules`).

| المسار | المحتوى |
| --- | --- |
| `data/shared.js` | رابط الموقع، مكتبة المحطات المشتركة (`stations`)، المقاطع المشتركة (`segments`)، المسارات المشتركة (`routeTemplates`)، قائمة الفحص، الأدعية، الأماكن، التطبيقات |
| `data/i18n.js` | نصوص الواجهة بالعربية والإنجليزية (ومنها نصوص `js/app.js` و `manifest.json`) |
| `data/countries/*.js` | ملف واحد لكل دولة فعّالة (يُكتشف تلقائياً) |
| `data/site.js` | ترتيب الدول في الصفحة الرئيسية وبيانات صفحات «قريباً» |
| `templates/` | قوالب الصفحات (`country.js`, `home.js`, `coming-soon.js`, `manifest.js`, `sw.js`) والأدوات المشتركة `helpers.js` |
| `css/style.css` | أنماط صفحات الدول وصفحات «قريباً» |
| `css/home.css` | أنماط الصفحة الرئيسية |
| `css/fonts.css` و `assets/fonts/` | خط Tajawal مستضافاً محلياً (يُخزَّن للعمل دون اتصال) |
| `js/app.js` | السلوك التفاعلي لكل الصفحات |

الملفات المولّدة (لا تُعدَّل يدوياً): `index.html`، `<دولة>/index.html`، مجلد `en/` كاملاً، `manifest.json`، `sw.js`، `sitemap.xml`.

يتحقق GitHub Action (`.github/workflows/build-check.yml`) في كل طلب دمج أن البناء ينجح وأن الملفات المولّدة المودعة مطابقة للمصدر.

## اللغتان

كل صفحة تُبنى بنسختين ثابتتين: العربية في جذر الموقع (`/qatar/`) والإنجليزية تحت `en/` (`/en/qatar/`)، وبينهما زر تبديل (EN / ع) ووسوم `hreflang`. ولكل لغة ملف `manifest.json` خاص بها: يُستخدم حين يضيف الزائر الموقع إلى الشاشة الرئيسية لجواله، فتظهر الأيقونة باسم لغته وتفتح على رئيسيتها.

- النص المعروض في ملفات البيانات يُكتب بصيغة `{ ar: '...', en: '...' }`، والقيم المحايدة (روابط، أرقام، إحداثيات) تُكتب مباشرة.
- نصوص الواجهة الثابتة في `data/i18n.js`.
- النص العربي إلزامي ويفشل البناء دونه. الترجمة الإنجليزية الناقصة لا توقف البناء: يُعرض النص العربي مكانها، ويُطبع في نهاية البناء تنبيه بقائمة النصوص الناقصة.

## التعديل والبناء

عدّل ملفات `data/` أو `templates/` أو `css/` أو `js/` ثم شغّل:

```bash
node build.js
```

يحسب البناء تلقائياً: ترقيم المحطات، المسافة المتبقية لكل محطة ونقاط GPS، الوقود والزمن الصافي، بصمات الملفات (`?v=hash`)، قائمة كاش `sw.js`، وتاريخ «آخر تحديث» (تاريخ آخر إيداع غيّر المحتوى، أو اليوم إن وُجدت تعديلات غير مودعة).

## مسار الدولة: أقسام تختارها الدولة

لا يفترض البناء ممراً ثابتاً لكل الدول (مثل المرور بالرياض). كل دولة تحدد أقسام محطاتها بالترتيب:

```js
outbound: [
    { id: 'section-stations-start', title: {...}, stations: [...] }, // قسم خاص بالدولة
    'riyadhMain', 'riyadhBypassSalman', 'riyadhToMakkah'             // مقاطع مشتركة من shared.segments
],
return: ['madinahToRiyadh', { id: 'section-return-home', ... }]
```

- **المقاطع المشتركة** (`shared.segments`) أقسام جاهزة بعنوانها ونصها التمهيدي. الدولة التي تمر بطريق آخر (مثل تبوك ← المدينة) يُضاف لها مقطع جديد في `shared.segments` وتختاره، دون أي تعديل في القوالب أو `js/app.js`.
- **المحطات المشتركة** (`shared.stations`) تُستدعى بـ `{ ref: 'go-station-hwy40', distanceFromPrevKm, badge }`. بيانات المحطة (الاسم، الرابط، الإحداثيات) في مكان واحد، أما المسافة والشارة فتُكتب مع الاستدعاء لأنها تخص المقطع (المحطة السابقة ← هذه المحطة). ويمكن تخصيص `desc` عند الاستدعاء.
- **المسارات المشتركة** (`shared.routeTemplates`) لبطاقات «خيارات المسارات»: `{ ref: 'riyadhBypass', itinerary, distanceKm }`.
- **الترقيم** متصل داخل المرحلة (الذهاب أو العودة). القسم البديل (`numbering: 'alternative'`، مثل المسار الالتفافي) يبدأ برقم القسم السابق نفسه، و`'restart'` يبدأ من 1.
- **تحديد الموقع (GPS)**: كل نقطة مسار تحمل معرّف القسم الذي يقع فيه الطريق المؤدي إليها، فيميّز شريط الجوال «أنت هنا» لأي مسار.
- **الالتحاق بمقطع مشترك من نقطة أخرى**: مسافة أول محطة في المقطع مقيسة من محطة الالتقاء المعتادة (`startsFrom`). الدولة التي تصل إليه من مكان آخر تكتب مسافتها هي إلى أول محطة فيه، وشارة بديلة إن لزم:

  ```js
  { segment: 'riyadhToMakkah', joinKm: 38, joinBadge: { ar: 'تبعد ~38 كم عن ...', en: '~38 km from ...' } }
  ```

## الدول ذات المنافذ المختلفة: مسارات كاملة متعددة

بطاقات `routes` نوعان:

- **بطاقة وصفية** (الافتراضي): تشرح طريقاً بديلاً قريباً من المسار الرئيسي (مثل الالتفاف حول الرياض)، ولا تغيّر المسافة المتبقية ولا GPS.
- **مسار كامل**: بطاقة تحمل `outbound` خاصاً بها، تُستخدم حين يختلف المنفذ نفسه (عُمان عبر الربع الخالي أو عبر الإمارات، الأردن عبر الحديثة أو الدرة...):

```js
routes: [
    {
        id: 'empty-quarter',                       // المسار الأول هو الافتراضي
        switchLabel: { ar: 'عبر الربع الخالي', en: 'Via the Empty Quarter' },
        title, itinerary, description, mapUrl,
        distanceKm: 1650,                          // = totalDistanceKm للدولة
        outbound: [{ id: 'section-stations-start', ... }, { segment: 'riyadhToMakkah', joinKm: 120 }]
    },
    {
        id: 'via-uae',
        switchLabel: { ar: 'عبر الإمارات', en: 'Via the UAE' },
        title, itinerary, description, mapUrl,
        distanceKm: 1900,
        estimatedDriveHours: 22,                   // مطلوبة لغير المسار الافتراضي
        outbound: [...],
        return: [...]                              // اختياري: وإلا فـ return الدولة
    },
    { ref: 'riyadhBypass', ... }                   // بطاقة وصفية كما هي
],
return: [...]
```

- لا يُكتب `outbound` على مستوى الدولة حينها. لكل مسار كامل سلسلة GPS ومسافة يُتحقق منها كما في المسار الواحد.
- في الصفحة: أزرار «مسار رحلتك» أعلى «رحلتي الآن» وفوق محطات الذهاب، وزر «اعتماد هذا المسار» في بطاقته. يُحفظ الاختيار، وتُخفى أقسام المسارات الأخرى (ومنها الطباعة وقائمة «المحطات»)، وتتبعه المسافة والزمن وحاسبة الوقود.
- **GPS**: إن كان المسافر خارج المسار المختار لكنه على مسار كامل آخر، يُختار ذلك المسار تلقائياً. على مقطع يشترك فيه المساران يبقى اختياره كما هو.
- القسم الذي يمر به أكثر من مسار (مثل `riyadhToMakkah`) يُعرض لكل مسار بترقيمه، ويأخذ في المسار الثاني معرّفاً بلاحقة (`section-stations-makkah--via-uae`).

## المسافات: مصدر واحد

المصدر الوحيد للمسافات هو الحقل `distanceFromPrevKm` في كل محطة. سلسلة المسار هي:

```text
origin ← محطات أقسام الذهاب التي تدخل السلسلة (بالترتيب) ← الحرم المكي (toMakkahKm في آخر قسم)
```

أقسام الذهاب تدخل السلسلة افتراضياً، إلا ما وُسم `chain: false` (محطات بديلة داخل مدينة). المحطة الإضافية `unnumbered` (مثل استراحة طعام) لا تدخلها.

يفشل البناء برسالة واضحة إذا:

- لم يطابق مجموع المقاطع `totalDistanceKm` للدولة، أو مسافة المسار الرئيسي `routes[0].distanceKm`، أو `distanceKm` لأي مسار كامل آخر.
- ذكرت شارة أي محطة («تبعد ~N كم») مسافة تخالف `distanceFromPrevKm`، أو ذكرتها لمحطة بلا `distanceFromPrevKm` (يشمل محطات العودة)، أو ذكرتها في لغة دون الأخرى.
- لم تنتهِ محطات الدولة بالمحطة التي يُقاس منها المقطع المشترك التالي (`startsFrom`)؛ مثلاً `riyadhToMakkah` تُقاس مسافته من `{ ref: 'aldrees-riyadh-entry' }`. الدولة التي تلتحق به من نقطة أخرى تكتب `joinKm` (انظر أعلاه).
- غابت `toMakkahKm` عن آخر قسم في سلسلة الذهاب، أو وُجدت في غيره.
- تجاوزت المسافة المستقيمة بين نقطتين متتاليتين مسافة الطريق بينهما (إحداثيات أو مسافة خاطئة).
- نقص محطة اسمٌ أو وصف أو رابط خريطة، أو كانت إحداثياتها خارج النطاق الجغرافي المتوقع.
- تكرر معرّف بند في قائمة الفحص (معرّف البند هو مفتاح حفظ حالته لدى المستخدم) أو معرّف قسم في الصفحة.
- كان تباين `themeColor` أو `themeColorDark` أقل من 4.5 مع الأبيض أو مع خلفية المظهر النهاري (`#F9F7F1`)، أو لم يطابق `themeColorRgb` قيمة `themeColor`.

الإحداثيات (`lat`/`lon`) تُكتب لمحطات سلسلة المسار وتؤخذ من رابط الخريطة نفسه، ومنها تُبنى نقاط GPS. المحطة التي لم يُتحقق من موقعها تُترك بلا إحداثيات ويكون رابطها رابط بحث.

## العمل دون اتصال

- **القشرة** (الأنماط، السكربت، الخط، الرئيسية باللغتين، والصور التي تعرضها الصفحات فعلاً) تُخزَّن عند أول زيارة، ويتغيّر اسم كاشها مع أي تغيير فيها. صورة المشاركة (`kaaba.jpg`) وأيقونات الإضافة للشاشة الرئيسية لا تُخزَّن لأنها لا تُعرض داخل الصفحات.
- **صفحات الدول** تُخزَّن عند زيارتها (الصفحة المفتوحة ونسختها باللغة الأخرى) في كاش منفصل لا يُحذف عند التحديث، وتُحدَّث من الشبكة عند كل زيارة. فلا يحمّل الزائر أدلة كل الدول.
- مواقيت الصلاة تُحفظ ليومها، والكابتشا لا تُحمَّل إلا عند فتح قسم الاقتراحات.

## إضافة دولة جديدة

1. أنشئ `data/countries/<code>.js` على نمط `qa.js`: البيانات، `origin`، `routes`، `outbound`، `return` (أو مسارات كاملة متعددة إن تعددت المنافذ).
2. استخدم المقاطع والمحطات المشتركة الموجودة إن مرّ الطريق بها، أو أضف مقطعاً جديداً إلى `shared.segments` (مع عنوانه في `data/i18n.js`).
3. تأكد أن الـ `slug` موجود في `countriesOrder` داخل `data/site.js` (الدول العشر مدرجة مسبقاً).
4. أضف ملف العلم إلى `assets/images/` إن لم يكن موجوداً.
5. شغّل `node build.js`.

تتحول الدولة تلقائياً من صفحة «قريباً» إلى دليل كامل، وتُضاف إلى الصفحة الرئيسية وخريطة الموقع.
